# SQL Fundamentals Practice

## Project Overview

This repository contains SQL exercises completed in Databricks as part of my journey to strengthen my understanding of SQL fundamentals. Using a retail sales dataset, I practised writing queries to explore customer transactions, product categories, sales performance, customer demographics, and purchasing behaviour.

## Tools Used

* Databricks
* SQL

## SQL Concepts Practised

The exercises demonstrate the use of:

* SELECT
* FROM
* WHERE
* GROUP BY
* HAVING
* ORDER BY
* LIMIT
* BETWEEN
* IN
* Aggregate functions such as SUM, AVG, COUNT, MIN, and MAX

## Dataset

The retail sales dataset contains transaction-level information including:

* Transaction ID
* Customer ID
* Gender
* Age
* Product Category
* Quantity
* Total Amount

## Practice Questions

The SQL exercises were designed to answer questions such as:

1. Which product categories generated the highest total sales?
2. Which genders had an average transaction value above a specified amount?
3. Who were the highest-spending customers?
4. Which product categories recorded the most transactions?
5. What was the highest sale amount for each product category?
6. What was the minimum sale amount by gender?
7. Which categories had an average quantity sold greater than two?
8. What were the total sales among selected age groups and product categories?
9. Which categories recorded high maximum transaction values?
10. Which product categories had the highest average sales values?

## Purpose

The purpose of this repository is to document my practical learning of SQL and demonstrate my ability to use fundamental SQL functions to query, filter, group, aggregate, and analyse structured data in Databricks.
